This page helps you ask a question or share feedback or a suggestion about AID.

Write a title and your message in the form below; the message is required. The "Continue on GitHub" button opens the new-issue page of the AID repository on GitHub, labelled "feedback", with your text filled in. The issue is public, so others can follow it.

For a private message instead, use [Request a conversation](/contact/contact-request/).
