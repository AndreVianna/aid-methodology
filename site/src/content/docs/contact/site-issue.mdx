This page helps you report a problem with the AID documentation site, such as a typo, a broken link or an unclear passage.

Describe the problem in the form below. The form opens a prefilled issue in the AID repository on GitHub, in a new tab, labelled "site issue". You submit it there, with your own GitHub account.

If you came from the "Report an issue with this page" link at the foot of a page, that page is already filled in. Your name and email are optional, and an email you give appears in the public issue.
