This page helps you report a problem with the AID documentation site, such as a typo, a broken link or an unclear passage.

Fill in a title and describe the problem in the form below; both are required. The "Continue on GitHub" button opens the new-issue page of the AID repository on GitHub, labelled "site issue", with your text filled in.

The "Report a problem with this page on GitHub" link at the foot of most pages leads to the same GitHub page, with the page title and address already filled in.
