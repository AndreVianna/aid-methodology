This page lists the Reference pages and says what each one holds, so you can find a fact quickly.

## Reference pages

Each Reference page lists facts to look up. It does not teach. Steps and explanations live in the guides and concepts linked at the end of this page.

| Page | What it holds |
|------|---------------|
| [CLI commands](/reference/cli/) | The `aid` commands, their flags, exit codes, environment variables and tool ids. |
| [Skills](/skills/) | The skills, grouped by what they are for, with a page for each: what it does, how you call it, and a link to its source definition. The skills have their own sidebar group. |
| [Agents](/reference/agents/) | Every agent AID skills dispatch, with its default model tier, tools and definition. |
| [Knowledge Base documents](/reference/kb/) | The standard Knowledge Base document types and the template each one comes from. |
| [Settings keys](/reference/settings/) | The keys of `.aid/settings.yml`, the value a new install starts with, and what each key does. |
| [Artifacts](/reference/artifacts/) | The named files AID produces, what each one is, and where it lives. |
| [Repository structure](/reference/repository-structure/) | How the AID repository is laid out and where things live. |
| [Glossary](/reference/glossary/) | The terms you meet in AID, with a definition for each. |

## Steps and explanations

To install AID, follow the [Installation guide](/guides/installation/). To run the pipeline, follow [Working the pipeline](/guides/pipeline/). To learn what AID is and why it works this way, read [the methodology](/concepts/methodology/).
