We keep questions and reports public, so the answer helps the next person too. You need a free GitHub account.

| I want to... | Go here |
| --- | --- |
| Report something wrong or unclear in these docs | [Open a documentation issue](https://github.com/AndreVianna/aid-methodology/issues/new?template=feedback.yml) |
| Report a bug in AID itself | [Open an issue](https://github.com/AndreVianna/aid-methodology/issues/new) and include your AID version (`aid version`), your AI tool and what you ran |
| Ask a question or suggest an idea | [Open an issue](https://github.com/AndreVianna/aid-methodology/issues/new) |
| Contribute a fix or a skill | Read [CONTRIBUTING.md](https://github.com/AndreVianna/aid-methodology/blob/master/CONTRIBUTING.md) |
| Talk to the team privately | Use the contact details at [casuloailabs.com](https://casuloailabs.com) |

Every docs page also has a "Report a problem with this page" link at the bottom. It opens the documentation form with the page already filled in.
