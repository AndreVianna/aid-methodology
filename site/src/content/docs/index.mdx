## The problem AID solves

An AI coding agent is fast, but with a vague task and a big codebase it guesses. AID adds process, not prompt tricks.

<ul class="aid-points">
  <li><strong>It learns your code first</strong><span>A Knowledge Base records how the project really works, with a file and line for every claim.</span></li>
  <li><strong>You approve each step</strong><span>Requirements, design, plan and tasks each stop at a gate. Nothing moves on without your OK.</span></li>
  <li><strong>Small, checkable tasks</strong><span>Work is cut into typed tasks with acceptance criteria, so the agent cannot quietly add scope.</span></li>
  <li><strong>A second agent checks the first</strong><span>The agent that writes never grades its own work. A reviewer with a clean context does.</span></li>
</ul>

## Install in two steps

First install the `aid` command once per machine. Then add AID to a project.

<Tabs syncKey="os">
  <TabItem label="Linux / macOS">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AndreVianna/aid-methodology/master/install.sh | bash
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://raw.githubusercontent.com/AndreVianna/aid-methodology/master/install.ps1 | iex
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm i -g aid-installer
    ```
  </TabItem>
  <TabItem label="pipx">
    ```bash
    pipx install aid-installer
    ```
  </TabItem>
</Tabs>

Open a new terminal, go to your project, and add AID for your AI coding tool:

```bash
aid add claude-code
```

Other tools: `codex`, `cursor`, `copilot-cli`, `antigravity`. Then, in your AI tool, run `/aid-config`. The [install guide](/get-started/install/) has every option, offline installs included.
