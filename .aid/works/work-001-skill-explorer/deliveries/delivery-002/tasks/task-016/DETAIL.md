**Scope:**
- Insert one new top-level sidebar group into `site/astro.config.mjs`, immediately after the `Reference` group and before `Releases`: label `Skills`, with `{ label: 'All skills', slug: 'skills' }` **first** in `items`, followed by `{ label: 'Every skill', collapsed: true, items: [{ autogenerate: { directory: 'skills' } }] }`.
- Both details are load-bearing, not cosmetic. `All skills` must be `items[0]` because `Header.astro` derives the tab's destination from `links[0]?.href`. The autogenerated subgroup is what makes the Skills tab **highlight on a detail page** -- `isActive` is `links.some((l) => l.isCurrent)` over the group's recursively collected links, so with only the index registered the tab would never highlight on any of the 111 detail pages and every one of them would sit outside the site's navigation.
- The nested-`items` form is required: Starlight >= 0.39.0 removed the combined `label` + `autogenerate` form, as `astro.config.mjs`:79-80 already records.
- The edit is confined to the `sidebar` array. The `mermaid({ ... })` options object and the `components:` map are **not** touched by this task.
- **This delivery is the first to open `site/astro.config.mjs`, and two one-line ride-alongs are proposed for it -- both PENDING OWNER APPROVAL rather than assumed, and neither is in delivery-002's gate criteria.** KI-012: `enableLog` defaults to true, so the production site logs `[astro-mermaid] ...` to every visitor's console on every page, and this work multiplies that by 111 pages -- the fix is `enableLog: false` in the `mermaid({ ... })` options. KI-013: the component-map comment claims the map is empty when it holds four keys, and reserves slots using a *previous* work's `feature-NNN` numbers. If the owner approves either, it lands in this same edit because this is the first edit to the file; if not, both stay open. **Risk R1:** this file has three would-be editors across the work (this group, delivery-005's `components:` key, and conditionally delivery-003's KI-001 repair) -- they must be sequenced, never applied concurrently.
