**Scope:**
- Create `site/scripts/lib/flow-graph/classify.mjs`: `classifySkill({ name, dir, frontmatter, body })` implementing discriminators D1-D5 in **strict precedence, first match wins**, and returning `{ shape, evidence, delegatesTo }` per task-019's seam 4 decision.
- D1 `dispatch-table`: a heading of level >= 2 whose text is **exactly** `Dispatch` or `State Machine`, followed before the next heading by a GFM table whose header row carries both a `State` and an `Advance` column. Both clauses are load-bearing -- the engine file has an earlier `## Dispatch Protocol` heading whose section holds no table, and an `## Invocation Contract` table whose columns are `Value | Source | Notes`; a discriminator matching a heading *containing* `Dispatch` would select the wrong one and yield zero nodes.
- D2 `inline-states`: two or more headings matching `^##\s+State:\s+\S`. D3 `sibling-doorway`: the body declares it carries no logic of its own (case-insensitive `no logic of its own`) **and** references exactly one other skill's `canonical/skills/<name>/SKILL.md` -- this is where `delegatesTo` is captured. D4 `engine-doorway`: the `GENERATED by ... build-shortcut-skills.py` HTML comment, **or** a body reference to `canonical/aid/templates/shortcut-engine.md`. D5 `residual`: none of the above.
- **Classification is by inspection of the body only.** The classifier MUST NOT read `canonical/aid/templates/shortcut-catalog.yml` at all, and specifically not its `repurpose` flag: that flag marks rows the build script must never overwrite, and it is carried by both `aid-review` (221 lines, a full inline state machine) and `aid-test-security` (25 lines, pure delegation) -- structurally opposite skills.
- **No per-shape count may be hard-coded**, here or in this module's tests. The population is an *output* of this classifier; `shapeCounts` in the manifest (task-030) is the only authority.
- Conventions: `site/`-local 2-space ESM, `node:`-scheme builtins only, no new dependency, pure exported function with no import-time side effect.
