# Independent review

Review the plan against the original request before building. Review each completed milestone against the repository and actual checks, then review the whole result against the request and repository. For a site, inspect rendered pages, cross-page consistency, accessibility and claims against current source; record missing tools or permissions instead of claiming visual verification.

For each finding, record the request text it misses, the repository fact and location it contradicts, or the failing check output. Only a finding supported by one of these blocks. Record whether the finding changed the result. Present other observations to the user without another review loop.

After one fix round, check the fixes and rerun affected checks. If a supported finding remains, stop and show the user its evidence; do not silently accept it or call the work complete.
